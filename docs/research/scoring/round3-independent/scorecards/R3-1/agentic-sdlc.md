## Default path trace (scenario R)
1. Install: `/plugin marketplace add …` + `/plugin install …` (Claude Code) or `npx agentic-sdlc-method --bundle agentic-sdlc -y` (README.md "Get started"). Node ≥ 18 is optional; without it the method runs "prompt-only" (quickstart.md Prerequisites).
2. Entry point: router `skills/agentic-sdlc/SKILL.md` Step 0 state 1 → `project-context` in **adopt** mode (existing codebase): baseline test run, `docs/codemap.md`, AGENTS.md block with `sdlc-dod`, scripts vendored to `.agentic-sdlc/bin/`, approval before writing (project-context/SKILL.md Steps 0–9; references/paths.md §5).
3. Discover: Analyst scores the path (references/paths.md §2). R's feature touches 5–20 files, which exceeds the Quick file bound ("Quick > 3 files", paths.md §4 Escalate, and router Step 1 "more files than the path bound (Quick > 3 …) → stop, re-score, route up"); Quick also has no plan for 3–10 tasks (writing-plans/SKILL.md: Quick → "No plan"). Files 4–15 → 2 or > 15 → 3, components ≥ 1, iterations 1 → S ≥ 5 in the typical API + client case; either way the method's own bound puts R on **Standard** (Full if a Full-forcing trigger or R ≥ 2 applies).
4. Specify (spec-driven-development): `spec.md` from template with AC-n, non-goals, Security notes, Rollback, Release & observability; fresh-context doubt pass; `spec-lint`; Product Owner sign-off (combined with Design when ≤ 5 tasks), recorded with rev + hash + register row.
5. Design (writing-plans): `plan.md` tasks with signatures, Files, Blocked by, AC; `plan-graph` → `graph.json`, waves; Tech Lead sign-off; Test Engineer writes `acceptance-tests.md` from the spec on branch `at/NNN-slug` (references/verification.md §2).
6. Build (executing-plans, attended): `run-ledger start` + `preflight` (clean tree, branch, approvals bound to hashes, baseline DoD); per task red → green → refactor, `run-ledger red/round/task`, scoped re-check, per-task review, loop bounds and breakers; commits `Refs: Tn AC-n`; PR body from template.
7. Test: Reviewer in fresh context, L1 then L2–L4 in parallel, merge/dedup, verify, severity, receive mode, scoped re-review (≤ 3 rounds); Verification rows with fingerprint, Trace two-way gap analysis, default NO-GO; human Test sign-off on the PR.
8. Release + Operate: release checklist with rollback rehearsal, go/no-go, staged rollout, Release Owner sign-off; ops record; retro within 5 business days (references/release-ops.md, retrospective.md).
Not on R's default path: CI gates, branch protection and CODEOWNERS (prepared by `project-context` enforce mode and installed by `deployment-pipeline` in rollout week 3, references/adoption.md); unattended mode (opt-in, evaluated as offered for C8).
