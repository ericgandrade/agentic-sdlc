## Default path trace (scenario R)
Entry: README 'Get started' -> `uv tool install specify-cli`, `specify init --here --integration <agent>` (existing project per docs/how-to/existing-projects.md: reviewable baseline branch, init in place, constitution from existing README/ADRs/CI).
Route: docs/quickstart.md offers a 'Shorter path - for smaller features' and a 'Full path - for production features'. R is a production feature, so the full path is the default path for R.
1. /speckit-constitution (once) records principles; plan later gates against it.
2. /speckit-specify writes specs/NNN-x/spec.md (user stories with Given/When/Then, FR-###, SC-###) and runs a self-validation checklist (checklists/requirements.md, max 3 iterations, max 3 [NEEDS CLARIFICATION] questions).
3. /speckit-clarify asks up to 5 questions one at a time, logs Q->A in a dated Clarifications session.
4. /speckit-plan writes plan.md, research.md, data-model.md, contracts/, quickstart.md; Constitution Check gate.
5. /speckit-checklist (reviewer-owned requirement-quality checklists) -> /speckit-tasks (T### with [P] and [US#], dependency section) -> /speckit-analyze (read-only consistency and coverage report).
6. /speckit-implement executes tasks by phase (stops if checklists unchecked; halts on failed sequential task) -> /speckit-converge appends gap tasks; repeat implement/converge until 'Converged', then 'proceed to review or open a PR' (team's normal review; no review command in core).
