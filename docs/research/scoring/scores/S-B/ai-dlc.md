## Default path trace (scenario R)
Entry: install native `aidlc` (curl script), `aidlc config --harness claude`, `aidlc doctor`, then `/aidlc <request>` (README Quick Start).
Route: the agent proposes a stock profile from the request (docs/guide/05-scopes-and-depth.md 'The Agent Proposes the Plan'). The chooser lists `feature` as 'Best for: a production feature using the complete lifecycle' (docs/guide/workflow-profiles.md), so R is scored on `feature` (Standard depth, guard_policy off, sensors/learnings on, plan approval on, collaborators off, skeleton on). CONTESTABLE: `classic` is the engine default when nothing is proposed (harness/claude/settings.json AWS_AIDLC_DEFAULT_SCOPE=classic); classic skips Ideation/Operation and caps reviews at advisory. Cells sensitive to this choice (C5, C6, C12) carry lowered confidence.
1. Initialization (state, scaffold, workspace detection); brownfield -> Reverse Engineering writes codekb (architecture, code-structure, dependencies...).
2. Ideation and Inception stages, each ending in an Approve/Request Changes gate: Requirements Analysis (FR/NFR IDs, out of scope, all [Answer] tags filled, traceability.json), User Stories (AC IDs), Units Generation (YAML DAG), Delivery Planning, etc. Reviewer subagents and deterministic sensors run at gates.
3. Construction per Unit: functional/NFR design, Code Generation (Plan Approval enforced by PreToolUse hook unless the guard stands aside; test-first per Testing Posture; traceability to code paths), checkpoint verification with a human-authorized command and tool-written proof; adversarial review (default class) with engine-capped passes.
4. Build and Test (coverage gate from traceability tables; loop-back to Code Generation max 3 by root cause), CI Pipeline.
5. Operation (conditional stages): deployment pipeline (rollback runbook, feature flags), execution (smoke/health), observability (alarms, SLO), incident response, performance validation, feedback into next Ideation. Learnings ritual at each gate turns corrections into rules or sensors.
