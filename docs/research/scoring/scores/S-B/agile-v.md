## Default path trace (scenario R)
Entry: README 'Start in 60 Seconds' (clone, copy skill directories), then choose an installation profile and follow docs/GOLDEN_JOURNEY.md.
Route for R: risk level L2 (docs/agile-v-runtime/04_RISK_CLASSIFICATION.md rule 2 and 11_RISK_ASSESSMENT_V2.md floor: production release is at least L2). Profile `existing-repo` (docs/INSTALL_PROFILES.md: changing an existing codebase), which is core-minimal + existing-repo evidence skills + the verified-build skills (build-agent, test-designer, red-team-verifier, agile-v-quality-gates) plus one domain build skill. Companion skills (pipeline, lifecycle, compliance, release-manager, threat-modeler, observability-planner) are not in that profile; where the Golden Journey names one, the cell notes it.
1. Gate 0 understanding, impact analysis and regression selection on the existing repo (skills/system-understanding-agent, impact-analysis-agent, regression-selection-agent).
2. Risk register entry; requirement-architect persists draft REQ-XXXX with verification and done criteria; logic-gatekeeper records independent FND findings without editing; architect revises.
3. Human Gate 1 approval recorded; revision frozen into a baseline.
4. build-agent implements from the baseline with typed lineage and build manifest; test-designer derives TC from the baseline in a separate context.
5. red-team-verifier executes tests, records VER findings with severity and failure codes, re-verifies after fixes (max 3 attempts then escalate); Eval Gate.
6. Evidence bundle and Human Gate 2 (rollback evidence required at L2); release via release-manager per Golden Journey step 11.
