## Default path trace (scenario R)

1. Install: `uv tool install specify-cli`, `specify init --here --integration <agent>` (existing repo: docs/how-to/existing-projects.md — reviewable baseline branch, constitution from repo evidence).
2. Route: docs/quickstart.md offers a "Shorter path — for smaller features" and a "Full path — for production features". R is a production feature, so the **full path** is selected: constitution (once) → specify → clarify → plan → checklist → tasks → analyze → implement → converge.
3. `/speckit-specify` writes `specs/NNN-x/spec.md` (Given/When/Then scenarios, FR-###, SC-###) plus `checklists/requirements.md` and self-validates (max 3 iterations); up to 3 [NEEDS CLARIFICATION] questions go to the user.
4. `/speckit-clarify` asks up to 5 questions one at a time and records `## Clarifications / ### Session` Q→A lines in the spec.
5. `/speckit-plan` writes plan.md (Constitution Check gate), research.md, data-model.md, contracts/, quickstart.md; `/speckit-checklist` writes reviewer-owned requirement-quality checklists.
6. `/speckit-tasks` writes tasks.md (T### IDs, [P] parallel markers, [USn] labels, file paths; tests only if requested); `/speckit-analyze` is a read-only cross-artifact consistency/coverage report.
7. `/speckit-implement` gates on unchecked checklists (asks), executes phase by phase, marks [X]; `/speckit-converge` inspects code against spec/plan/tasks and appends gap tasks; repeat until "Converged", then "proceed to review / open a PR" (no review command in core).
