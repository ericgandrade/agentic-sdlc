## Default path trace (scenario R)

1. Install as a plugin (one command, e.g. `/plugin install superpowers@claude-plugins-official`); a SessionStart hook loads `using-superpowers`, which makes the agent check for skills before any task.
2. R request → `brainstorming` auto-triggers: reads the existing code first, asks one question at a time, lays out approaches, sizes the work ("a small change" vs "a project"); R is a project, so a full design doc goes to `docs/superpowers/specs/…-design.md`, gets a fresh-subagent builder check, and the HARD-GATE requires the human's approval.
3. `writing-plans` → `docs/superpowers/plans/…md` with Global Constraints, Review Focus, per-task Files/Interfaces and red→green→commit steps with exact commands; self-review; human reviews the plan and chooses Subagent-driven (recommended in the plan header) or Native execution.
4. `using-git-worktrees` creates an isolated worktree and verifies a clean test baseline.
5. `subagent-driven-development`: ledger in a git-ignored workspace, preflight conflict scan; per task a fresh implementer (TDD skill) → review package (BASE..HEAD) → fresh task reviewer (spec compliance + quality, severity) → fix loop (≤5 rounds, scoped re-review, breaker) → ledger line. Runs continuously, stopping only for four named conditions.
6. Final whole-branch review on the most capable model, one fix wave + one scoped re-review, "Rulings I made" list, then `finishing-a-development-branch` (full test run, merge / PR / keep / discard chosen by the human).
